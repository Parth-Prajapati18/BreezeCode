# Objects and Arrays

Objects are collections of key-value pairs, while arrays are ordered lists of values.

## Objects

Objects are defined using curly braces `{}`.

### Example Code

```javascript
let person = {
  name: "John Doe",
  age: 30,
  isStudent: false
};

console.log(person.name); // John Doe
