# Control Flow

Control flow statements are used to control the flow of execution in a program. JavaScript provides several control flow statements including conditional statements and loops.

## Conditional Statements

- `if` statement
- `else` statement
- `else if` statement
- `switch` statement

## Loops

- `for` loop
- `while` loop
- `do...while` loop

### Example Code

```javascript
let age = 18;

if (age >= 18) {
  console.log("You are an adult.");
} else {
  console.log("You are a minor.");
}

for (let i = 0; i < 5; i++) {
  console.log(i);
}
