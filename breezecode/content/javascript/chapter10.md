# ES6 Features

ECMAScript 6 (ES6) introduced several new features to JavaScript that make it easier to write and maintain code.

## Let and Const

`let` and `const` are block-scoped variable declarations.

### Example Code

```javascript
let variable = "This can be changed";
const constant = "This cannot be changed";
