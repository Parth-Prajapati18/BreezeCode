# Operators and Expressions

Operators are used to perform operations on variables and values. JavaScript includes various operators such as arithmetic, assignment, comparison, logical, and more.

## Arithmetic Operators

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)

### Example Code

```javascript
let sum = 10 + 20; // 30
let difference = 20 - 10; // 10
let product = 10 * 20; // 200
let quotient = 20 / 10; // 2
let remainder = 20 % 10; // 0
